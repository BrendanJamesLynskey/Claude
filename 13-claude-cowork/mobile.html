04

A Worked Task

Anthropic’s example: receipts to an expense report. Documented flow; illustrative wording.

  1. Connect a folder: ~/Expenses/October (Trusted folders)
  2. Describe the outcome: “Turn these receipts into a spreadsheet: one row each, totals by category.”
  3. Choose how it checks in: Auto (Pro, Max, Team) or Manual (Enterprise)
  4. Claude plans and runs code in the sandbox, fetching each receipt via the desktop app
  5. Steer from anywhere: answer questions on your phone; get notified
  6. Get the file: preview, download, refine; then “Every Monday at 9 AM, add last week’s receipts.”

Deleting files always needs your Allow. For real consequences, stay close or use Manual.

05

How It Runs

New Pro/Max tasks run in the cloud (Team by default, Enterprise if enabled). Your computer joins only through the desktop app.

  • Keeps going with the laptop closed
  • No route to private, internal or metadata addresses
  • Isolation doesn’t limit what Claude can read or do with the access you grant
  • Team/Enterprise data isn’t used for training; consumer plans follow your privacy setting
06

Local Mode — VM on Device

A local session runs the agent loop natively and code inside a Linux VM that the desktop app hosts.

Who Runs Locally

  • Pro/Max tasks from before 6 Oct 2026; Team/Enterprise local sessions; HIPAA local mode; Desktop on 3P

VM Needs

  • Linux: KVM, kvm group, QEMU, ~25 GB disk, 8 GB RAM (4 GB in use)
  • macOS 14+ (Apple silicon or Intel); Windows 10 19041+ x64/Arm64, .msix, Virtual Machine Platform (3P guide)
  • Keep the app open and the computer awake
  • No VM: shell says “workspace unavailable”

Injection Needs Two Things

Claude must both read untrusted content and be able to act against you. Remove either and the attack gets much harder.

08

Connectors & MCP

Claude picks the most precise tool first:

  • Connectors: directory or HTTPS URL; calls made server-side, tokens never in the sandbox
  • Private servers: Enterprise MCP tunnels (preview)
  • Local MCP (.mcpb, plugin-bundled): via the desktop app only
  • Skills and plugins load from Customize; ~/.claude is ignored
  • Browser: built-in (default) or Claude in Chrome; asks before a new site; high-risk sites blocked
09

Long-Running & Scheduled

Long tasks run without conversation timeouts; cloud sessions continue with the laptop closed.

Scheduled Tasks (All Paid Plans)

  • Ask: “Every weekday at 8 AM, summarise my team’s Slack channels” → Schedule
  • Or Scheduled → New task: hourly, daily, weekly, weekdays or manual
  • Run in the cloud, unless they need local files or apps

Unwatched Means Careful

  • Start with low-risk summaries
  • No sensitive files, messages as you, or purchases
  • Review each run; pause unused tasks

Dispatch (Winding Down)

  • Phone-to-desktop thread; runs on your computer
  • Limited beta; not available to new users

12

Limits & Gotchas

Limits

  • Paid plans only
  • No session sharing; share artifacts
  • Computer use: beta, Pro/Max, macOS and Windows only
  • Multi-step tasks use more of your usage
  • Pro/Max: no choice of where tasks run
  • New experience: no Add from GitHub, no branching

Gotchas

  • App closed: task runs on, but can’t reach your computer
  • Egress settings don’t cover web search, web fetch or MCP
  • Egress changes apply to new sessions only
  • Built-in browser logins carry over to later sessions
  • ~/.claude skills need adding in Customize

Something off? Stop the task and report it with the feedback button.
